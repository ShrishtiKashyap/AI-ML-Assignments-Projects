# ResearchForge-AI

## Overview

ResearchForge-AI is a Retrieval-Augmented Generation (RAG) chatbot that combines web search, document processing, and Large Language Models to provide grounded and context-aware answers. The application is built with Streamlit and integrates modern AI frameworks for intelligent research assistance.

## Features

- Retrieval-Augmented Generation (RAG)

- Document Processing
- Large Language Model Integration
- Interactive Streamlit Interface
- Context-Aware Responses
